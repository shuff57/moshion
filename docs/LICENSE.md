## 4. A note on `assets/`

Until 2026-08-25 this directory held six files that were **byte-identical**
to the example art shipped with q5play, while section 1 above described them
as original work for this course. That was not correct.

They were replaced with art generated by `scripts/make-moshion-assets.py`,
which draws every pixel from primitives and reads no source image. The sheet
geometry is unchanged, because the lessons that load them slice by frame
count: `asterisk_explode.avif` 11 frames, `ghost_idle.avif` 7,
`ghost_fly.avif` 4, and `star.webp` a single static image.

`monster.webp` and `questKid.webp` were deleted rather than redrawn -- no
lesson, doc or example referenced either one.

Re-run the script to regenerate the sheets; it is deterministic.
